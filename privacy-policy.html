Kebijakan privasi

Kebijakan ini menjelaskan aliran data saat Anda menggunakan situs statis CuanSeller.

Input kalkulator

Harga, biaya, fee, dan angka lainnya diproses di memori browser perangkat Anda. Aplikasi tidak mengirim input tersebut ke server, tidak memiliki database, dan tidak menyimpannya ke localStorage atau sessionStorage. Browser Anda sendiri dapat memulihkan nilai formulir saat memulihkan tab atau riwayat navigasi.

Cookie dan analitik

Kode situs CuanSeller tidak memasang cookie, layanan analitik, iklan pihak ketiga, font eksternal, atau pelacak pengguna. Tidak ada pendaftaran akun maupun proses pembayaran.

Layanan hosting

Saat situs diakses melalui internet, penyedia hosting dapat menerima informasi teknis seperti alamat IP, waktu akses, URL yang diminta, dan jenis browser dalam log server. Pencatatan dan masa simpan log bergantung pada konfigurasi penyedia hosting, di luar pemrosesan kalkulator di browser.

Kendali Anda

Gunakan angka simulasi jika Anda tidak ingin mengetik data usaha asli. Tutup tab setelah menggunakan perangkat bersama. CuanSeller tidak memegang salinan input kalkulator untuk diakses atau dihapus dari server aplikasi.

Perubahan kebijakan

Kebijakan ini perlu ditinjau kembali jika situs menambahkan analitik, formulir pengiriman, atau layanan eksternal. Baca juga cara kerja CuanSeller dan batas penggunaan hasil.
